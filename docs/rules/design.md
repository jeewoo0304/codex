# 퍼블리싱 및 UI 검수 규칙

이 저장소 전체(`codex-project`)가 `design` UI 퍼블리싱 영역입니다. 별도의 `design/` 하위 폴더를 만들지 않습니다. 저장소 루트의 `src/`에서 재사용 컴포넌트, 디자인 기반 요소, 실행 가능한 페이지 미리보기를 관리합니다. 계획된 모든 화면을 찾아서 시각적으로 검수할 수 있어야 합니다. 이 영역은 실제 금융 서비스 앱이 아닙니다.

## 구조와 원칙

- 공통 컴포넌트는 목적과 재사용 범위에 따라 배치하고 명확한 TypeScript props 타입을 사용합니다.
- 색상, 타이포그래피, 공통 스타일 등 디자인 기반 요소는 별도 모듈에서 관리합니다.
- 미리보기 페이지는 예금, 대출 등 업무 여정별로 구성합니다. 메뉴나 경로 목록을 통해 전체 페이지를 확인할 수 있게 합니다.
- 미리보기는 가상 데이터만 사용하고 운영 서비스나 인증 정보 없이 실행되어야 합니다.
- 미완성 영역은 눈에 띄는 플레이스홀더와 간단한 코드 주석으로 표시합니다.
- 미리보기에서 UI 상태를 표현할 수 있지만 실제 금융 거래를 처리해서는 안 됩니다.
