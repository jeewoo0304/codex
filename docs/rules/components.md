# 공통 컴포넌트 작성 규칙

- 재사용 표현 컴포넌트는 퍼블리싱 영역에 작성하고 실제 앱과 미리보기에서 함께 사용합니다.
- 컴포넌트는 역할을 작게 나누고 props 기반으로 작성합니다. 외부에 공개하는 컴포넌트에는 명시적인 props 타입을 선언합니다.
- 컴포넌트는 전달받은 데이터와 상태를 표현합니다. 데이터 조회, 도메인 판단, 업무 계산은 이를 소유하는 앱이나 도메인에 둡니다.
- 의미에 맞는 HTML을 사용하고 키보드 조작, 포커스 표시, 레이블, 접근 가능한 상태 표현을 지원합니다.
- 공통 토큰과 반응형 레이아웃 스타일을 우선 사용합니다. 이미 토큰이 있다면 색상과 간격을 개별적으로 하드코딩하지 않습니다.
- 컴포넌트의 변형이나 상태 사용법이 자명하지 않으면 컴포넌트 또는 사용 안내에 설명합니다.
