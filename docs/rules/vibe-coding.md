# 바이브코딩 작업 절차

AI 코딩 도구를 활용해 작업 속도를 높이되 제품·데이터·보안 경계를 분명히 유지합니다.

## 코드 변경 전

1. 요청이 실제 앱 영역(`apps/`)인지, 현재 저장소 전체인 UI 퍼블리싱 영역(`codex-project`)인지, 공통 규칙 문서인지 확인합니다. UI 작업은 이 저장소의 `src/`에서 진행합니다.
2. 해당 영역의 규칙과 주변 코드, 기존 구현 방식을 확인합니다.
3. 작업 요청에는 대상 파일과 기대 동작을 구체적으로 적습니다. 금전 이동, 권한, 데이터 처리, 되돌리기 어려운 흐름의 요구사항이 불분명하면 먼저 확인합니다.

## 구현 중

- 요청을 충족하는 가장 작은 단위로 변경합니다. 금융 규칙, API 계약, 사용자 데이터를 임의로 만들어내지 않습니다.
- UI 미리보기는 실제 서비스와 분리하고 가상의 테스트 데이터를 사용합니다.
- 요청 범위 밖의 동작은 유지합니다. 가정이 필요하면 이를 기록합니다.
- 실제로 실행하지 않은 명령이나 검증을 성공했다고 보고하지 않습니다.

## 작업 완료 시

- 변경한 영역과 가정, 남은 문제를 요약합니다.
- 요청되었거나 저장소 절차에서 필요한 검사만 실행하고 결과를 정확히 알립니다.
- 비밀 정보, 실제 개인정보·금융 데이터, 요청과 무관한 변경이 포함되지 않았는지 확인합니다.
