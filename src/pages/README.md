# 퍼블리싱 미리보기 페이지

화면을 시각적으로 확인하기 위한 UI 조합을 둡니다. 운영 API에 연결하지 말고 데이터가 필요하면 `src/data/`의 가상 목 데이터를 사용합니다.

- `home/`: 랜딩 및 대시보드 미리보기
- `accounts/`: 계좌 목록 및 상세 미리보기
- `transfers/`: 이체 화면 미리보기
- `deposits/`: 예금 및 적금 화면 미리보기
- `loans/`: 대출 화면 미리보기
- `cards/`: 카드 화면 미리보기
- `auth/`: 로그인 및 본인 확인 화면 미리보기

새 화면은 관련 도메인 폴더에 추가하고, 미리보기 메뉴나 경로 목록에서 찾을 수 있도록 연결합니다.
