# 금융 서비스 UI 퍼블리싱

이 저장소(`codex-project`) 전체를 `design` 퍼블리싱 영역으로 사용합니다. 별도의 `design/` 하위 폴더는 두지 않습니다.

## 범위

- `src/components/`: 실제 앱에서도 재사용할 UI 컴포넌트
- `src/pages/`: 전체 금융 서비스 화면을 확인하기 위한 퍼블리싱 미리보기
- `docs/rules/`: 앱, UI 컴포넌트, 데이터, 바이브코딩 작업 규칙

이 저장소는 UI 검수 영역이므로 운영 API에 의존하거나 실제 금융 거래를 수행하지 않습니다. 미리보기에는 가상 목 데이터만 사용합니다. 실제 기능과 데이터/API 연동은 별도의 `apps/` 영역에서 담당합니다.

## 실행

```bash
npm install
npm run dev
```
